# Irish Nicole Palomo — Web Design Portfolio

A responsive seven-page student portfolio for Web Design (ELEC 4106), featuring a green visual theme, personal and classroom photographs, and the eight course units.

## Pages
1. Home
2. Instructor
3. About Me
4. Lessons
5. Activities
6. Reflections
7. Contact

## Files
- HTML files contain the seven portfolio pages.
- `assets/css/` contains the website styles.
- `assets/js/` contains the mobile navigation behavior.
- `assets/images/` contains the portfolio photographs.
- `assets/lessons/` contains the eight lesson presentations in PDF format.

## Run locally
Open `index.html` in a modern web browser. For the best experience, keep the `assets` folder in the same directory as the HTML files.

## Design and accessibility
The portfolio uses a consistent forest-green and sage palette, responsive page layouts, semantic HTML, descriptive image text, keyboard-friendly navigation, and clear heading structure.
