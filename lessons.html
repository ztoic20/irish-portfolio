The course materials

Lessons & Learning Materials

Explore the eight units of Web Design (ELEC 4106). Each section includes a short overview and access to the original lesson presentation.

U1
UNIT 1

Introduction to Web Design

The foundations of an effective website

Introduces the language and purpose of web design, the difference between web design and web development, common website types, and the principles that help a website work well for its audience.

  • Key terms and definitions in web design
  • Web design versus web development
  • Types of websites and their purposes
  • Principles and importance of good web design

U2
UNIT 2

Planning a Website

Purpose, audience, structure, and content

Explores the planning work that should happen before a website is built. It connects the website’s purpose and target users with the site map, wireframes, content plan, and brand elements.

  • Define the website purpose and target users
  • Create a site map and basic wireframes
  • Plan text, images, and multimedia content
  • Identify brand elements such as logos, colors, typography, and tone
View Unit 2 presentation

U3
UNIT 3

Introduction to HTML and CSS

Structure and style for web pages

Explains how HTML provides the structure of a web page while CSS controls its visual presentation. The unit introduces basic document structure, semantic elements, common tags, styling rules, and responsive design.

  • HTML tags, elements, attributes, and document structure
  • Headings, paragraphs, lists, links, and images
  • Clean and semantic HTML
  • CSS selectors, properties, values, layout, and media queries
View Unit 3 presentation

U4
UNIT 4

Web-Based Tools for Website Platforms

Exploring website builders and content platforms

Introduces online applications that help users build, manage, and publish websites. The unit explores platforms such as Google Sites, Wix, WordPress, and other tools, with attention to their features and suitability for different needs.

  • What web-based website tools are and how they work
  • Google Sites
  • Wix
  • WordPress and other website platforms
View Unit 4 presentation

U5
UNIT 5

Getting Started with Google Sites

Pages, themes, layouts, and content blocks

Covers the Google Sites interface and the steps for creating a multi-page website. It focuses on selecting a theme, organizing navigation, arranging page sections, and adding text, buttons, images, galleries, links, and embeds.

  • Navigate the Google Sites toolbar, sidebar, and workspace
  • Choose and customize a theme
  • Create and organize pages and navigation
  • Add text, buttons, images, galleries, links, and embedded content

U6
UNIT 6

Embedding Office Tools, Branding and Style Guidelines

Useful content with a consistent visual identity

Shows how embedded office tools can make a website more useful and interactive. It also explains why a style guide matters and how colors, typography, logos, imagery, and layout should remain consistent across pages.

  • Embed Google Forms, Docs, Sheets, Slides, and calendars
  • Manage and update website content
  • Apply logos, brand colors, and typography
  • Maintain consistent page layouts and embedded content
View Unit 6 presentation
Open PDF ↗ Download lesson ↓
U7
UNIT 7

Accessibility, Mobile View and Publishing

Make the website usable across devices

Focuses on making website content easier to access and navigate. The unit covers descriptive alt text, readable contrast, heading structure, keyboard navigation, mobile preview, link testing, sharing permissions, and publishing.

  • Write meaningful alternative text for images
  • Check text contrast, headings, and descriptive links
  • Preview and adjust phone and tablet layouts
  • Test navigation and review publishing settings
View Unit 7 presentation
Open PDF ↗ Download lesson ↓
U8
UNIT 8

Office Website Presentation and Keyboarding

Present the website and learn from feedback

Explains how to present a completed website by describing its purpose, audience, design, layout, key features, technical choices, user experience, and accessibility. It also emphasizes responding to feedback and identifying improvements.

  • Introduce the website purpose and intended audience
  • Explain design, layout, branding, and key features
  • Demonstrate navigation and website functions
  • Receive feedback and identify possible improvements
